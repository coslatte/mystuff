# CosmicLatte

Portafolio personal de [coslatte](https://github.com/coslatte) — desarrollador y músico.

Muestra proyectos, música y permite comentar y votar tracks.

## Stack

- **Frontend** — Astro + React + Tailwind v4 + Bun
- **Backend** — Spring Boot + JPA + Flyway + PostgreSQL
- **Despliegue** — Vercel (frontend) / Render o Railway (backend)

## Estructura

```
backend/   # API REST (canciones, comentarios, ratings)
frontend/  # Sitio web (Astro)
```

## Enlaces

- SoundCloud · Bandcamp · YouTube · GitHub — en el footer del sitio.
